Bookstore App :

Overview :
  This project is a Bookstore App that enables users to add, view, update, delete, and favorite books.
  It provides a user-friendly interface for managing a collection of books efficiently.

Features: 
  CRUD Operations: Users can create, read, update, and delete books.

  Favorite Books: 
      Users can mark books as favorites for easy access.

  Responsive Design: Works seamlessly across different devices.

  Database Integration: Stores book data securely.

Technologies Used:
  Frontend: HTML, CSS, JavaScript

  Backend: Spring Boot (Java)

  Database: MySQL

  Styling: Bootstrap


Installation & Setup : Clone the repository: git clone link of repository cd bookstore-management-app

Build and run the project: Open the application in a browser run on 8080
